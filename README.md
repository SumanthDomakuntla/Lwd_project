# LWD Mail — Sign Off

A static recreation inspired by the uploaded reference reel.

## Run
Open `index.html` in a browser. No server or build step is required.

## Customize
Open `index.html` and edit the `people` array near the bottom:

{
  name: "Person Name",
  note: "Your personal farewell message..."
}

The page automatically creates the cards and the personal-note modal.

## Features
- Dark cinematic/aurora background
- Responsive desktop/mobile layout
- Animated colleague cards
- Personal-note modal
- Keyboard Escape to close
- No external JavaScript libraries


## Adding photos
Put additional images inside `photos/`, e.g.:
`memory-02.jpg`, `memory-03.jpg`, etc.

Then add each image to both the gallery HTML and `galleryImages` array in `index.html`.
